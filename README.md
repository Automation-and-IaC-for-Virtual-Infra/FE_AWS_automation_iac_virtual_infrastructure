# AWS Flow

A project for VPBank Hackathon leveraging AWS services.

## Features

- Cloud-native architecture
- Scalable and secure
- Easy deployment

## Requirements

- Node.js >= 24
- AWS CLI configured
- Docker (optional)

## Getting Started

```bash
git clone https://github.com/your-org/aws-flow.git
cd aws-flow
npm install
```

## Usage

Update your AWS credentials and run:

```bash
npm start
```
